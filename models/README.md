# Carpeta del modelo entrenado

Después de ejecutar el notebook `notebooks/RNN_IMDB_Sentimiento.ipynb` en Google Colab hasta
el final, descarga los dos archivos que genera (`modelo_sentimiento_imdb.keras` y
`class_names.json`) y colócalos en esta carpeta. La app de Streamlit los busca exactamente aquí:

```
models/modelo_sentimiento_imdb.keras
models/class_names.json
```
